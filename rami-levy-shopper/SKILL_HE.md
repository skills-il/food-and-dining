# קניות ברמי לוי דרך שורת הפקודה

השתמשו בפרויקט הקוד הפתוח [`rami` CLI](https://github.com/bornio/rami-levy-cli)
בשם הקונה. התמקדו בהחלטת הקנייה ובתוצאה, ולא במימוש הטכני של הכלי.

זהו פרויקט קהילתי לא רשמי שאינו קשור לרמי לוי ואינו נתמך על ידיו. השתמשו בו
רק עם החשבון של הקונה ובהתאם לתנאי השימוש של רמי לוי.

## הוראות

### שלב 1: ודאו שהכלי מותקן ושהחשבון מחובר

הריצו `rami --version`. אם הפקודה לא זמינה, התקינו את החבילה הציבורית מ-npm
והריצו שוב את בדיקת הגרסה:

```sh
npm install --global rami-levy-cli
rami --version
```

השתמשו [בהוראות ההתקנה של הפרויקט](https://github.com/bornio/rami-levy-cli#install--about-2-minutes)
לדרישות העדכניות. אל תאלתרו פניות ישירות ל-API הפרטי של אתר רמי לוי.

אם פעולה מדווחת שאין אימות או שפג תוקפו, הריצו:

```sh
rami auth login
```

תנו לקונה להזין סיסמה וקודי אימות בדף האמיתי שנפתח ב-Chrome. לעולם אל תבקשו
פרטי התחברות בצ'אט. העדיפו התחברות בדפדפן; התייחסו אל
`rami auth import <file.har>` רק כחלופה ידנית ורגישה.

### שלב 2: קראו נתוני קנייה עדכניים

לבקשות קריאה אפשר להריץ מיד:

```sh
rami cart
rami search "מילות חיפוש"
rami search "מילות חיפוש" --sort price
rami search "מילות חיפוש" --sort unit-price
rami orders
```

השתמשו ב-`rami --help` או ב-`rami help <command>` לתחביר העדכני. הציגו לקונה
את הפלט הרגיל. הוסיפו `--json` כשצריך שדות מדויקים לצורך ניתוח, ואז סכמו את
התוצאה במקום להציג JSON גולמי, אלא אם התבקש אחרת.

התייחסו לכל פקודת עגלה כקריאה חיה: היא מושכת את העגלה מהשרת ומחשבת מחדש את
המחירים העדכניים. אל תענו מפלט עגלה ישן כשנדרש המצב הנוכחי.

### שלב 3: בחרו והשוו מוצרים

- העדיפו מוצרים זמינים ולאחר מכן את דרישות המחיר, האריזה או המותג של הקונה.
- זהו מוצר לפי שם, גודל או תכולת האריזה, מחיר ומזהה מוצר.
- אם יש כמה התאמות סבירות, הציגו רשימה קצרה של האפשרויות הטובות ושאלו שאלה
  אחת קצרה לבחירה.
- אל תניחו שתוצאות החיפוש כוללות את כל הקטלוג; רמי לוי עשוי להחזיר פחות
  תוצאות ממספר ההתאמות המדווח.
- השתמשו ב-`--sort unit-price` להשוואה לפי משקל, נפח או יחידות, אבל השוו רק
  משפחות מדידה תואמות ובדקו את תכולת האריזה. נתוני היחידה של רמי לוי עלולים
  להיות חסרים או שגויים, ולכן אל תציגו את הדירוג כאמת מוחלטת.
- הפרידו בין מחיר רגיל, מחיר העגלה הנוכחי, חיסכון, הערכת משלוח ותנאי מבצע.
- התייחסו למחיר מבצע כתקף רק כשהשרת מאשר שהכמות הנוכחית בעגלה עומדת בתנאים.
  אל תניחו שליחידה נוספת יהיה אותו מחיר ממוצע.
- תארו סכומים כהערכה העדכנית, לא כהבטחה למחיר הסופי בקופה.

### שלב 4: שנו את העגלה בבטחה

זהו את מזהה המוצר והכמות המדויקים לפני שינוי. בצעו בקשה מפורשת וחד-משמעית
בלי לבקש אישור נוסף; אם המוצר, הגרסה או הכמות אינם ברורים, שאלו שאלה אחת קצרה.

```sh
rami cart add <product-id> [quantity]
rami cart update <product-id> <quantity>
rami cart remove <product-id>
```

- השתמשו ב-`add` כדי להגדיל את הכמות הקיימת; הפקודה אינה קובעת כמות מוחלטת.
- השתמשו ב-`update` כדי לקבוע כמות מוחלטת.
- השתמשו ב-`remove` כדי להסיר מוצר. אל תשתמשו בכמות אפס כתחליף.
- לעולם אל תרוקנו את העגלה או תסירו פריטים אחרים בלי בקשה מפורשת.
- שמרו על מזהי מוצר בדיוק, כולל אפסים מובילים.
- השתמשו רק בכמויות חיוביות עם עד שתי ספרות אחרי הנקודה.

לאחר הצלחה, דווחו את שם המוצר שאומת, הכמות שהתקבלה, זמינות, מחיר השורה
העדכני, חיסכון שהוחל והסכום המעודכן של המוצרים הזמינים, אם הנתונים קיימים.

אם שינוי מדווח על שגיאה או שהעדכון נשמר אך הפרטים לא נטענו, אל תחזרו על
הפעולה. הריצו קודם `rami cart` כדי לברר את התוצאה בשרת; חזרה על `add` עלולה
להכפיל את הכמות.

### שלב 5: הגנו על נתוני הקונה והישארו בגבולות הכלי

- לעולם אל תציגו, תקראו, תעתיקו או תכניסו ל-Git פרופילים שמורים, טוקנים,
  cookies או תוכן של קובצי HAR.
- השתמשו בפרופיל המחובר כברירת מחדל, אלא אם הקונה בחר במפורש פרופיל אחר.
- אל תשנו את קוד המקור של ה-CLI כדי לבצע בקשת קנייה.
- אל תטענו שביצעתם הזמנה. הכלי מנהל חיפוש, הזמנות עבר ועגלה; התשלום הסופי
  מתבצע באתר רמי לוי.

## דוגמאות

### דוגמה 1: הצגת העגלה הנוכחית

המשתמש אומר: "מה יש לי עכשיו בעגלה של רמי לוי?"

הריצו `rami cart`. הציגו קודם את המוצרים הזמינים, ציינו מוצרים שאינם זמינים,
הציגו חיסכון שהוחל ואת סכום המוצרים הזמינים. הבהירו שזהו המחיר העדכני ושמשלוח
אינו כלול אלא אם הוצג בנפרד.

### דוגמה 2: מציאת הסודה המשתלמת ביותר

המשתמש אומר: "מצא את הסודה הכי זולה לליטר ברמי לוי."

הריצו `rami search "סודה" --sort unit-price`. השוו רק מוצרים עם נתוני נפח
תואמים. הציגו זמינות, נפח אריזה, מחיר נוכחי ומחיר ליחידה, והזהירו בקצרה שצריך
לבדוק את נתוני האריזה.

### דוגמה 3: הוספת מוצר לא חד-משמעי

המשתמש אומר: "תוסיף שני בקבוקי סודה של מי עדן."

חפשו `מי עדן סודה`. אם קיימים גדלים או סוגים שונים, הציגו את ההתאמות הטובות
ושאלו באיזו לבחור. לאחר הבחירה, הריצו `rami cart add <product-id> 2` ודווחו
את הכמות והמחיר העדכניים שאומתו מול השרת.

## פתרון תקלות

### שגיאה: `rami: command not found`

סיבה: הכלי אינו מותקן או מקושר במחשב.

פתרון: הריצו `npm install --global rami-levy-cli` ואז הריצו שוב
`rami --version`. אל תחליפו את הכלי בפניות API מאולתרות.

### שגיאה: חסר אימות או שתוקפו פג

סיבה: פרטי ההתחברות המצומצמים אינם קיימים או שכבר אינם תקפים.

פתרון: הריצו `rami auth login` ותנו לקונה להשלים את ההתחברות ב-Chrome. לעולם
אל תבקשו להדביק סיסמה או טוקן בצ'אט.

### שגיאה: שינוי עגלה נכשל או שתוצאתו אינה ודאית

סיבה: ייתכן שהשרת קיבל את השינוי לפני שקריאת מחיר או רשת מאוחרת יותר נכשלה.

פתרון: הריצו `rami cart` לפני ניסיון נוסף. השוו את הכמות החיה לתוצאה המבוקשת
והסבירו מה נמצא.

### שגיאה: תוצאות החיפוש עמומות או שחסרים נתוני יחידה

סיבה: שמות המוצרים, גרסאות האריזה או נתוני רמי לוי אינם מאפשרים בחירה בטוחה.

פתרון: הציגו את האפשרויות הסבירות עם מזהה, גודל, זמינות ומחיר. בקשו מהקונה
לבחור ואל תנחשו.
